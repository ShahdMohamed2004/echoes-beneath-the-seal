# Privacy policy

Effective 10 October 2026. Created and Designed by Shahd Mohamed.

The single-player game has no implemented accounts, advertising, analytics, tracking pixels, remote AI or crash-reporting services. Progress, dialogue history, language and settings remain in local browser/app storage. The offline cache stores public game assets. Save export/import occurs only at the player's request. There is no automatic cross-device synchronization.

Deleting app/browser data or uninstalling can remove progress. Export a backup first. Android automatic app backup is disabled in the supplied native project.

The web edition uses GitHub Pages hosting. GitHub may log network and request metadata under its own privacy policy. Game code, graphics, fonts and sound are served locally from the selected deployment, not from third-party asset CDNs. Native builds bundle the same files.

The game requests no microphone, camera, location, contacts or advertising permission. Import reads a user-selected save file locally without uploading it. The GitHub issue tracker is the support route; issues may be public, so avoid posting personal information there.

Public policy route after deployment: `privacy.html`. Store data-safety declarations must be checked against the exact signed package and its final dependencies before submission. No submission or certification is represented by this document.
