# Original contemporary Egyptian cast

Each runtime atlas has 21 states × four authored pixel frames at 48×80. Design sheets show front, profile and action views. The turn animation transitions through three-quarter and profile poses. The infection/hybrid previews for ordinary citizens are design studies, not assertions that those people become infected in the story. Only narratively eligible actors use infection states.
