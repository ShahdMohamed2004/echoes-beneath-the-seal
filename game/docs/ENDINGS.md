# Ending conditions

Eight original outcome types are retained. Flags/evidence are canonical IDs rather than raw evidence counts. Day 15 must be reached before finish() accepts a final choice.

| Ending | Conditions |
|---|---|
| TRUE ENDING | Reveal truth; Echo print decision preserved; no wipe; self opened; Patient 07 evidence; all four proved deductions. |
| THE TRUTH | Reveal truth; Echo preserved and not wiped; incomplete true-ending proof. |
| THE SILENCE | Bury truth; or request exposure after evidence was wiped/unavailable; or open a personal file without having opened it. |
| THE SURVIVOR | Leave with no active infection; also fallback from unsupported sacrifice. |
| THE INFECTED | Leave with active infection, including sacrifice fallback without resources/support. |
| THE SACRIFICE | Sacrifice after sharing with survivors or while holding medicine. |
| THE LOOP | Open last file after personal discovery, with self evidence and the erasure deduction. |
| THE LAST FILE | Open discovered personal file without the complete erasure link. |

## Required true-ending deductions

- responsibility: **signature + self** → I authenticated the transfer without knowing its purpose. Selecting contradictory claims does not add a deduction.
- coverup: **transfer + deleted** → Record deletion concealed the group transfer. Selecting contradictory claims does not add a deduction.
- outbreak: **hala + echo** → The experiment preceded the outbreak; the cover-up enabled its spread. Selecting contradictory claims does not add a deduction.
- erasure: **researcher + erasure** → Salim erased my memory and returned me to authenticate identities. Selecting contradictory claims does not add a deduction.

## Acquisition walkthrough

Receive/inspect citizens through day four to identify Patient 07. Inspect researcher visits or reveal an early lamp imprint for aliases. On day five, open the drawer and put the transfer paper beneath the lamp for the signature. Inspect CCTV on day six. Search Hala (4410) on day eight. Accept Samir’s key and open the archive on day nine for deleted names. Use Yasser’s pass or the key for lab access. On day thirteen search ECHO, print it, collect the page and choose preservation. On day fourteen search YOU, inspect the file and reveal the erasure imprint beneath the lamp. Use the journal to choose the four supported relationships before exposing the truth.

Refusing both the pass and key cannot trap the player. Restricted records on days thirteen/fourteen provide an explicit access-refusal path to the negative decision. Unavailable files cannot be opened through an alternative dialogue choice. Erasing records likewise retains a playable route to the finale.

The core tests enumerate all 1,024 combinations of ten binary narrative choices, using the available fallback when access is denied. Browser tests cover both the proof route and the refusal route. This does not constitute playtesting every authored line or native platform.
